# Game Design Document

## Fantasía
Sentir que trabajar en equipo permite superar obstáculos imposibles individualmente.

## Core Loop
Moverse → Coordinarse → Evitar obstáculos → Mantener la caja segura → Llegar a la meta

## Jugadores
2 jugadores cooperativos locales.

## Win State
Llegar a la meta con la caja.

## Fail State
La caja cae o ambos jugadores fallan.
