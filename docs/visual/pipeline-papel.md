# Pipeline: papel → PNG (Juanes & Matias)

Solo dibujas. No Blender. No PlayCanvas. No código.

## Herramientas (gratis)

| Orden | Herramienta | Uso |
|---|---|---|
| 1 | Papel + marcador oscuro | Dibujo con líneas cerradas |
| 2 | Celular (buena luz) | Foto centrada, sin sombra de mano |
| 3 | [Photopea](https://www.photopea.com) | Contraste, borrar fondo, export PNG |
| Alt | [remove.bg](https://www.remove.bg) | Quitar fondo rápido |
| Alt | [Vectorizer.ai](https://vectorizer.ai) | Carteles / texto limpio → SVG/PNG |

## Pasos

1. Dibujar en papel blanco.  
2. Fotografiar.  
3. Photopea → subir contraste → borrar fondo.  
4. Exportar **PNG transparente**.  
5. Nombrar bien y subir a tu carpeta en `deliveries/`.

## Qué hace Danel con tu PNG

- Carteles/META → los pega en un **plano** en el nivel.  
- Caja → textura o panel sobre el cubo.  
- Personajes → referencia de look; el cuerpo en juego puede seguir siendo cápsula hasta Capa C.
