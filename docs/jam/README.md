## Cómo subir más material

1. Rama `work/<tu-nombre>` (Luis → `work/luis`)
2. Copia el archivo a `docs/jam/` (nombres claros, sin espacios raros)
3. Commit + push + **PR a `dev`**
4. Al mergear a `dev`, el sync alimenta al resto de `work/*`

No subas zips enormes del build del juego aquí: el build jugable va por [`DEPLOY.md`](../DEPLOY.md) (Pages / itch).
