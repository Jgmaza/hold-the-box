# Prompts — Juanes (dibujo personajes + caja)

Úsalos para brief / refs. El entregable final sigue siendo **tu dibujo a mano** + PNG.

## Brief P1 / P2
```
Describe en bullets fáciles de dibujar dos personajes cartoon family-friendly:
P1 traje negro y gafas; P2 gorra blanca, camiseta blanca, jeans.
Pose de cargar caja a dos manos. Silueta legible a distancia. Sin detalle excesivo.
Lista vistas: frente, 3/4, espalda, cargando.
```

## Estados de la caja
```
Lista 4 dibujos de una caja de cartón tipo whisky Old Parr para game jam:
1) normal 2) inclinada 3) con huequito perdiendo algo 4) mojada/goteando.
Indica qué debe verse claro en cada uno para que un programador entienda el estado.
```

## Checklist de foto
```
Dame checklist de 8 puntos para fotografiar dibujos en papel y que se vean bien
antes de pasarlos por Photopea (luz, ángulo, recorte, contraste).
```
